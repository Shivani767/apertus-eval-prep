\section{Experimental Setup}
\label{sec:setup}
The evidence boundary is the successful-run registry, not every file in the repository. It contains \RunCount{} measurements: eight shared greedy configurations for SmolLM2-1.7B-Instruct, Qwen2.5-3B-Instruct, and Phi-3.5-mini-instruct; three sampled seeds each for Smol and Qwen; and one Qwen2.5-7B-Instruct INT4 cell. The last model is excluded from shared rankings. The planned Phi sampling arm is missing. No Apertus model appears in this evidence boundary.

Each run contains the same \ItemCount{} IDs: 200 each from ARC-Easy test, GSM8K test, HellaSwag validation, and MGSM test pooled across English, German and French \citep{clark2018think,cobbe2021training,zellers2019hellaswag,shi2022language}. The snapshot script shuffles with seed 0 for scored items and seed 1 for exemplar selection. Hub revisions are documented in the data manifest; local slice bytes are hashed by our pipeline. Repeated outputs across configurations are not independent benchmark questions. MGSM translations and GSM8K-related questions create potential dependence even between distinct local IDs.

The declared control uses HF generation, tokenizer chat-template selection, default zero-shot instructions, temperature 0, top-$p$ 1, seed 0, no quantization, maximum 256 new tokens and batch size 1. Variants change prompt ID (concise or five-shot), backend (vLLM), quantization (HF bitsandbytes INT8 or NF4), or greedy seed (1 or 2). Sampling jointly changes temperature to 0.7 and top-$p$ to 0.95, with seeds 0, 1, and 2: a decoding-policy bundle, not an isolated temperature effect. Default math instructions request reasoning; concise requests only an answer. Five-shot uses frozen answer-only demonstrations. The appendix specifies current instruction and exemplar files.

The design is nominally one-factor-at-a-time (OFAT), relative to a declared baseline. Strict OFAT requires all other effective settings to remain fixed. Historical software drift, unrecorded revisions and precision resolution prevent verifying that condition here. We report associations, not isolated causal backend/quantization effects. No completed real factorial matrix is present in the selected registry. OFAT cannot recover interactions among configuration dimensions; heterogeneous model responses do not substitute for an interaction experiment.

\paragraph{Recorded environment.}
Manifests report Tesla T4 hardware. Precision is recorded as \texttt{dtype=auto}, not resolved arithmetic precision. Model and tokenizer revisions: \emph{Version not recorded in the current artifact.} Rendered chat templates, driver versions, and complete dependency locks are unavailable. The audit records multiple Python, Transformers, vLLM and harness version strings; these are per-run metadata, not a single shared environment. Current backend code has different precision-selection paths with and without quantization. We cannot certify byte-identical historical prompts or effective generation defaults across backends.

\subsection{Statistics}
We re-score every stored generation using the current extractor and verify correctness, predictions, frozen IDs and gold answers against the artifacts. Accuracy uses exact integer counts; rounding occurs only for display. Wilson marginal intervals \citep{wilson1927probable} describe a binomial approximation. Paired differences use task-stratified item bootstrap percentile intervals (4,000 replicates, RNG seed 0). Within each task, paired correctness differences are resampled with replacement, preserving task sizes. This quantifies conditional item-sampling uncertainty, not configuration selection, software drift or language/question-cluster dependence.

We use two-sided exact conditional McNemar tests \citep{mcnemar1947note}, conditioning on the total number of discordant item pairs. Under the null and independent pairs, wins are binomial with probability one half. No discordant pairs yields $p=1$. Holm adjustment \citep{holm1979simple} is applied without intermediate rounding to \ContrastCount{} same-model non-control contrasts; a separate post-hoc family contains eight shared Phi/Qwen comparisons. That pair was selected after observing the top scores, so these tests are exploratory, not confirmatory. Intervals are pointwise, not multiplicity-adjusted; related questions may make item-independent inference optimistic. Non-significance does not establish equivalence.
